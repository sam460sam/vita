# Vyta — Life OS

A personal all-in-one life OS: one hub for health and activity, projects, habits, journaling and goals. Mobile-first, offline-first, installable as a PWA, and shipped as a native iOS app through Capacitor.

**Live on the App Store** → [apps.apple.com/app/id6776238780](https://apps.apple.com/app/id6776238780)

Built and shipped solo.

---

## Stack

- React 18 + TypeScript + Vite
- Tailwind CSS with design tokens as CSS variables (`src/styles/index.css`)
- Dexie (IndexedDB) behind a typed data layer
- React Router (`HashRouter`, deep-link safe)
- lucide-react for icons, date-fns for dates, charts in native SVG
- vite-plugin-pwa (manifest, service worker, offline)
- Capacitor for the native iOS and Android shells

## Commands

```
npm install      # install dependencies
npm run dev      # development (http://localhost:5173)
npm run build    # type-check + production build in dist/
npm run preview  # serve the production build
npm run lint     # type-check (tsc --noEmit)
```

PWA icons are generated by `node scripts/gen-icons.mjs` (one-off, no dependencies).

## Design decisions

**Everything stays on the device.** All data lives in IndexedDB through Dexie. There is no backend, no account, no sync server. The App Store privacy label is *Data Not Collected*, and that was a constraint from the first commit rather than a feature added later — it shaped the data layer, the export flow and the way state is handled throughout.

**HashRouter over BrowserRouter.** Deep links have to survive inside a Capacitor WebView and on static hosting without server-side rewrites.

**Charts in hand-written SVG.** A charting library would have added weight for a handful of simple visualisations, and the bundle size matters more than the convenience here.
